# 🍽️ MealWise

An AI-powered meal planning application that provides personalized meal recommendations based on user preferences and nutritional requirements. The application leverages Machine Learning, cloud computing, and modern web technologies to deliver a scalable and user-friendly experience.

---

## 🚀 Features

- 🤖 AI-powered meal recommendations
- 🥗 Personalized diet planning
- 🔐 Secure authentication using AWS Cognito
- ☁️ Cloud deployment with AWS
- 🔄 RESTful API architecture
- 📱 Responsive React frontend
- ⚡ CI/CD using GitHub and AWS Amplify

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/nishant5367/MealWise.git
```

Move into the project directory

```bash
cd MealWise
```

Install dependencies

```bash
npm install
```

Run the frontend

```bash
npm start
```

Run the backend

```bash
npm run server
```
